# Persistent Clicker Privacy Policy

Effective date: 2026-08-17

Persistent Clicker handles only the data needed to run a selected timer on your device. It does not transmit, sell, or share user data and has no analytics, advertising, accounts, or network service.

## Data handled on your device

Persistent Clicker processes website content locally so you can select a page control and click it on a schedule. It stores the selected CSS selector and label, interval, status, next scheduled time, and click count in Chrome session storage for the selected tab. The dashboard reads the tab title so you can recognize an open timer. Page content, selectors, titles, schedules, and usage details never leave your browser.

Session state is deleted when you close the tab or browser, disable or reload the extension, or remove the extension. You can stop a schedule at any time from the popup or dashboard.

## Permissions

- `contextMenus` adds the commands used to select a page control and open the timer dashboard.
- `scripting` reconnects the selector and timer controls to a page that was already open when the extension was installed or reloaded.
- `storage` keeps per-tab schedules in Chrome session storage while the browser session remains open.
- Access to HTTP, HTTPS, and user-enabled local file pages lets the selected control be found and clicked after that page reloads or navigates. Chrome internal pages and the Chrome Web Store remain inaccessible.

## Limited use

Persistent Clicker's use of information received from Chrome APIs complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. Data is used only to provide the user-facing interval-clicking feature and is not transferred to anyone.

## Changes and questions

Material changes to this policy will be published with an extension update before changed data practices take effect. Privacy questions can be submitted through the support channel linked from the Chrome Web Store listing.
